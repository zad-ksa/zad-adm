# بوّابةُ الملفّات — `files.zad-co.sa`

عاملُ Cloudflare يقرأ من مستودعِ باك بليز **الخاصّ** ويخدم الملفَّ على نطاقٍ
ثابت. وهو منشورٌ مستقلٌّ عن الموقع: لا يُبنى مع Next ولا يُنشر مع Vercel.

## لماذا هو موجود

| | لو عُمِّم المستودع | بالعامل |
|---|---|---|
| إعدادُ المستودع | عامّ (ويطلب تحقُّقاً) | **خاصٌّ كما هو** |
| الرابطُ في القاعدة | ثابت | **ثابت** |
| تعديلُ الكود | لا شيء | **لا شيء** |
| التخزينُ المؤقَّت | يعمل | يعمل |

والبديلُ الثالث — روابطُ موقَّعةٌ تنتهي — كان يفرض حفظَ المفتاح بدل الرابط،
وتعديلَ ثمانيةٍ وسبعين ملفّاً، اثنان وثلاثون منها مكوّناتُ عميلٍ لا تستطيع
التوقيعَ. فسقط.

**وما لا يفعله العامل:** لا يُخفي الملفَّ عن من يعرف رابطَه. وهو في ذلك
كمستودعٍ عامّ، وكحال روابط Cloudinary اليوم حرفاً — فلا أمانَ يُفقد بالنقل.
ومن أراد منعاً حقيقيّاً فموضعُه `index.mjs`: يُفحص كعكُ الجلسة قبل الجلب.

## النشر

```bash
cd workers/files
npx wrangler login
npx wrangler secret put B2_KEY_ID     # من صفحة Application Keys
npx wrangler secret put B2_APP_KEY    # ولا يُعرض إلّا مرّةً واحدة
npx wrangler deploy
```

وتُراجع قيمُ `[vars]` في `wrangler.toml` قبل النشر: المستودعُ والإقليمُ ونقطةُ
النهاية. **ولا يُوضع السرّان فيه** — هو ملفٌّ مُثبَّتٌ في المستودع.

### ثمّ في الموقع

```
STORAGE_PUBLIC_BASE=https://files.zad-co.sa
```

في `.env` **وفي Vercel معاً**، ثمّ نشرةٌ جديدة: سياسةُ المحتوى وقائمةُ مضيفي
الصور تُبنيان من هذا المتغيّر وقتَ البناء.

### وما يُحذف إن كان أُنشئ

- سجلُّ `CNAME` من `files` إلى `f003.backblazeb2.com` — `custom_domain` يُغنِي عنه.
- قاعدةُ التحويل التي تُزيل `/file/<bucket>` — العاملُ يُركّب المسار بنفسه.

## التحقُّق

```bash
npm run check:b2        # من جذر المشروع
```

يفحص السلسلةَ كاملةً: الإعدادَ، فالتوقيعَ، فالرفعَ، فوجودَ الملفّ، فقراءتَه من
`STORAGE_PUBLIC_BASE` بلا توقيع — وهذه هي التي تمرّ بالعامل — فالحذفَ، فزوالَه.

## ما يُنتبه إليه

**مُوقِّعان لمنطقٍ واحد.** `sigv4.mjs` هنا يستعمل Web Crypto لأنّ بيئةَ العامل
بلا `node:crypto`، و`src/lib/sigv4.ts` في الموقع تستعمله. ومن عدّل واحداً ونسي
الآخر، صار الموقعُ يرفع إلى مفتاحٍ والبوّابةُ تقرأ من غيره.

فـ`src/lib/workerSigv4.test.ts` يُقابلهما حرفاً على خمسةِ مُدخلات، ويسقط عند
أوّل افتراق — وهو يعمل مع `npm run test:lib` بلا إعدادٍ زائد.

**القراءةُ فقط.** العاملُ يرفض غيرَ `GET` و`HEAD`. والرفعُ يذهب من المتصفِّح إلى
نقطةِ نهاية S3 برابطٍ مُوقَّعٍ من الخادم، والحذفُ من الخادم — فلا كتابةَ تمرّ
من هنا بحال.
